# User Flows

## 핵심 학습 모델

`SEE` 블록 동작 확인 → `CONNECT` Python 표현 연결 → `CHANGE` 일부 코드 수정 → `RUN` 루미의 즉각적 결과 확인 → `CODE` 블록 의존도를 줄이며 직접 작성.

## Mission 01 Step 1

반복 블록 확인 → `for`와 `range()` 설명 확인 → starter code의 `2`를 수정 → 실행으로 루미 이동 확인 → 실패 시 해당 줄과 `range()` 힌트 확인 → `3`으로 성공 → 제출 → 기존 사용자 진도와 +40 XP 저장.

## 데모 회원 단계별 학습

로그인 → 저장된 첫 미완료 단계 복원 → 코드 수정·실행 → 결과 자동 저장 → XP 획득 → 다음 단계 해금 → 3단계 완료.

- 테스트 계정: `김하늘` / `2580`
- 비로그인 사용자는 1단계를 체험할 수 있지만 저장과 다음 단계 진행 시 로그인을 안내한다.

## 비회원 첫 체험

랜딩 → `로그인 없이 첫 미션 시작` → 블록/코드 비교 → 숫자 수정 → 실행 → 실패 힌트 또는 성공 → 로그인 후 저장 제안.

## 실패 복구

- 횟수 부족: 남은 칸 수를 알려주고 숫자를 늘리도록 유도.
- 횟수 초과: 지나친 칸 수와 정확한 거리를 안내.
- 문법 오류: 반복문 모양과 들여쓰기만 설명하고 정답 전체는 제공하지 않음.
- 언제든 초기화 또는 단계형 힌트 열기 가능하며 오류가 있는 줄을 시각적으로 확인한다.

## 회원 흐름(예정)

학생 이름·PIN 로그인 → 이어할 구역 → 미션 → 결과 저장 → XP/배지 → 다음 미션 해금.

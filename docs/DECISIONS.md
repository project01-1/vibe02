# Decisions

## 2026-08-04 — 첫 MVP에서 Python을 실행하지 않음

- 배경: 첫 미션은 반복 횟수 하나만 검증하면 되며 임의 코드 실행은 위험과 운영비가 크다.
- 대안: 서버 프로세스 실행, 브라우저 Python 런타임, 제한 문법 해석.
- 결정: 제한 문법 해석을 선택한다.
- 영향: 안전하고 빠르며 테스트 가능하다. 자유 코딩은 샌드박스 도입 전까지 지원하지 않는다.

## 2026-08-04 — 빈 저장소에 Sites vinext 기반 구성

- 배경: 프로젝트가 비어 있고 배포 가능한 반응형 웹 기반이 필요했다.
- 결정: Next.js App Router 호환 API와 Cloudflare Worker 호환 빌드를 제공하는 starter를 사용한다.
- 영향: 로컬 구조는 표준 React/TypeScript로 유지하고, Supabase는 어댑터로 후속 연결한다.

# Product Requirements

## Mission 01 Step 1 학습 UX P0

- 한 화면에서 `SEE → CONNECT → CHANGE → RUN → CODE` 흐름을 따라간다.
- 왼쪽은 미션·반복문 개념·블록 비교·Python 연결·단계형 힌트를 제공한다.
- 중앙은 starter code에서 `range(2)`의 숫자를 수정하며 줄 번호, 구문 강조, 자동 들여쓰기, 수정 지점과 오류 줄 강조를 제공한다.
- 오른쪽은 루미가 실제 이동 칸 수만큼 움직이고, 2칸이면 미도착, 3칸이면 에너지 셀 획득을 시각화한다.
- 실행은 안전한 로컬 미리보기, 제출은 기존 서버 검증·진도·XP 저장 계약을 사용한다.
- Mission 02·03, 인증, 기존 사용자 진도 데이터는 회귀 없이 유지한다.

## 로그인·저장 P0

- 고유한 학생 이름과 숫자 PIN 4자리로 로그인할 수 있다.
- 이름·휴대폰 번호·숫자 PIN 4자리로 회원가입할 수 있다.
- 세션과 학습 기록은 HMAC 서명된 HttpOnly 쿠키로 7일간 유지한다.
- 반복문, 변수, 조건문 3단계를 순서대로 완료하며 이전 단계가 완료되어야 다음 단계가 열린다.
- 작성 코드, 시도 횟수, 완료 상태, 완료 시각, 누적 XP를 사용자별로 저장한다.

## 사용자와 목표

- 핵심 사용자: 블록코딩 경험이 있는 초등 4~6학년.
- 목표 행동: 로그인 없이 3~5분 안에 코드의 숫자 하나를 바꾸고 실행해 첫 성공을 경험한다.
- 제품 톤: 개념 이해 구조 60%, 시각적 실행 피드백 40%. 과도한 보상·팝업·캐릭터 대사는 피한다.

## P0

- 랜딩: 제품 가치, 5단계 방식, 첫 미션, 6개 학습 구역, 저장 이점, CTA.
- 체험: 블록 비교, 편집기, 제한 문법 검증, 로봇 이동, 성공·실패·힌트·초기화.
- 품질: 반응형, 키보드 포커스, `prefers-reduced-motion`, 명확한 상태 피드백.

## 수용 기준

- 랜딩의 체험 CTA는 `/mission`, 인증 CTA는 `/login` 또는 `/signup`으로 연결된다.
- `range(3)`은 성공하고 더 작거나 큰 값은 방향성 있는 힌트를 준다.
- 임의 Python은 실행되지 않고 거부된다.
- 360px부터 데스크톱까지 가로 스크롤 없이 동작한다.

# Changelog

## 2026-08-11 — Supabase 영구 인증·진도 저장

- 서울 리전의 Python Future Lab 프로젝트에 PostgreSQL 스키마·RLS·초기 미션을 적용했다.
- 이름·고유 휴대폰 번호·숫자 4자리 PIN 회원가입과 로그인을 추가했다.
- PIN은 서버 HMAC으로 파생하고 로그인 실패 잠금과 서버 측 미션 재검증을 적용했다.
- 진도 upsert와 XP 지급을 원자적 DB 함수로 처리하고 Supabase 타입을 생성했다.
- 데모 쿠키와 D1/Drizzle 잔존 코드를 제거했다.

## 2026-08-04

- `김하늘 / 2580` 데모 학생 로그인과 서버 세션을 추가했다.
- D1 기반 학습 코드·진행 상태·시도 횟수·XP 저장 API를 추가했다.
- 반복문, 변수, 조건문으로 이어지는 3단계 순차 학습 화면을 추가했다.

## 2026-08-11

- Vercel의 `DEPLOYMENT_NOT_FOUND` 원인을 재현하고 Cloudflare 전용 빌드를 Next.js 네이티브 빌드로 전환했다.
- `vercel.json`을 추가하고 기본 개발·빌드·실행 명령을 Next.js 기준으로 변경했다.
- D1 의존 로그인 API를 Vercel 호환 HMAC 서명 쿠키 저장 방식으로 변경했다.
- Vercel의 pnpm 공급망 정책에 맞춰 필수 네이티브 빌드 패키지를 명시적으로 승인하고 Node.js를 22.x로 고정했다.

- 랜딩 첫 화면을 미래형 실험실 콘셉트의 코드 기반 모션그래픽으로 교체했다.
- 블록 시퀀스, 입자 에너지 스트림, CSS 로봇, Python 코드 타이핑, 포인터 패럴랙스를 추가했다.
- 모바일 반응형 구성과 모션 축소 접근성 대응을 추가했다.

- Python Future Lab 프로젝트를 초기화했다.
- 제품 전용 디자인 시스템과 반응형 랜딩 페이지를 추가했다.
- 로그인 없이 사용할 수 있는 첫 체험 미션을 추가했다.
- 허용 문법만 해석하는 안전 검증과 성공·실패·힌트·초기화 피드백을 추가했다.
- 제품·아키텍처·디자인·흐름·데이터·보안·의사결정·로드맵·작업 문서를 추가했다.

# Design System

## 학습 화면 원칙

- 데스크톱은 개념·코드·실행 결과를 약 33%씩 배분해 어느 영역도 지나치게 좁거나 넓지 않게 한다.
- 개념 패널은 `SEE`, `CONNECT`, `CHANGE`의 현재 위치를 짧은 문장과 블록 비교로 보여준다.
- 코드 편집기는 IDE를 모방하지 않고 줄 번호, Python 구문색, 자동 들여쓰기, 수정 대상·오류 줄 강조만 제공한다.
- 실행 패널은 텍스트 결과보다 루미의 이동, 경로, 목표물 상태를 먼저 보여주고 설명은 보조로 둔다.
- 성공 효과는 짧은 부유·수집 모션과 XP 카드로 제한하며, 실패는 정답 대신 다음 확인 지점을 알려준다.
- LEVEL 1은 블록/설명 60%, LEVEL 2는 50%, LEVEL 3은 20%, LEVEL 4는 기본 화면에서 블록을 제거한다.

## 히어로 모션 원칙

- 블록 입력 → 에너지 전달 → 로봇 번역 → Python 출력 순서가 시선 흐름과 일치해야 한다.
- 배경 영상 대신 HTML/CSS/React로 구성해 해상도와 화면 비율에 관계없이 선명하게 유지한다.
- 반복 모션은 1~12초 범위로 엇갈리게 구성하며, `prefers-reduced-motion`에서는 즉시 정지 상태로 수렴한다.
- 1020/760/480px 구간에서 콘솔·로봇·코드 모니터의 비율을 단계적으로 축소한다.

## 원칙

- 미래지향적이되 학습 내용을 압도하지 않는다.
- 깊은 네이비 배경, 블루 인디고 표면, 바이올렛 주 강조, 시안 보조 강조를 사용한다.
- 상태는 색상만으로 전달하지 않고 아이콘·문구를 함께 쓴다.

## 토큰

- Background: `#060B1D`, secondary `#0A1128`
- Surface: `#131F43` 계열 반투명 패널
- Primary: `#6659F6`, secondary `#3BD7E6`
- Success `#57E5B2`, warning `#FFC857`, error `#FF7184`
- Radius: 버튼 12px, 카드 15~20px

## 타이포그래피와 간격

- 시스템 한글 산세리프, 코드에는 Consolas/Monaco.
- 본문 최소 14px(핵심 학습 화면은 상황에 따라 11px 이상), 터치 영역 최소 40px.
- 8px 기반 간격, 섹션 78~108px.

## 접근성·반응형·모션

- 명확한 focus ring, 의미 있는 aria label/live region.
- 1020/760/480px에서 3열 → 2열 → 단일 열로 전환.
- 성공·실행 등 의미 있는 순간만 애니메이션하고 reduced motion에서 최소화한다.
